Web3Forms is highly recommended for a professional GitHub Pages site because it is free, reliable, and does not redirect the user away from your custom domain.

1. The HTML Form Structure
Add this structure to your contact page. Keep the name attributes clear, as these become the labels in your email notification.
<form id="contactForm">
    <!-- Replace with your actual key from web3forms.com -->
    <input type="hidden" name="access_key" value="YOUR_ACCESS_KEY_HERE">
    
    <!-- Anti-spam honeypot (Invisible to humans) -->
    <input type="checkbox" name="botcheck" class="hidden" style="display: none;">

    <label for="name">Name</label>
    <input type="text" id="name" name="name" required>

    <label for="email">Email</label>
    <input type="email" id="email" name="email" required>

    <label for="message">Message</label>
    <textarea id="message" name="message" required></textarea>

    <button type="submit">Send Message</button>
    <div id="formResult"></div>
</form>

2. The JavaScript POST Handler
This script intercepts the form submission, packages the inputs seamlessly, and fires a background POST request without reloading your static page.javascriptconst form = document.getElementById('contactForm');
const result = document.getElementById('formResult');

form.addEventListener('submit', function(e) {
  e.preventDefault();
  result.textContent = "Sending...";
  
  // Automatically packages all form fields based on their "name" attribute
  const formData = new FormData(form);
  const object = Object.fromEntries(formData);
  const json = JSON.stringify(object);

  fetch('https://web3forms.com', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json'
    },
    body: json
  })
  .then(async (response) => {
    let res = await response.json();
    if (response.status == 200) {
      result.textContent = "Success! Your message was sent.";
      form.reset(); // Clear the form fields
    } else {
      console.log(response);
      result.textContent = res.message;
    }
  })
  .catch(error => {
    console.log(error);
    result.textContent = "Something went wrong!";
  });
});

Essential Steps for GitHub Pages Custom Domains

Get an Access Key: Go to Web3Forms (or Formspree) and generate your free endpoint token using your professional email address.
Restrict Domain Access: Once your custom portfolio domain is live, go into your email provider's dashboard settings and turn on Allowed Domains. Enter your custom domain (e.g., yourname.com). 
This ensures that even if someone steals your access key from your source code, they cannot use it from any other website.

Letting users know the message was sent:
The "Form Disappear" Success Screen
This approach removes the form entirely after submission and replaces it with a clean, professional thank-you message. It leaves no doubt that the action was successful.

The CSS:
/* Add a helper class to hide elements */
.hidden {
  display: none !important;
}

/* Style your success message container */
#successMessage {
  text-align: center;
  padding: 40px 20px;
  background-color: #f0fdf4; /* Soft green */
  border: 1px solid #bbf7d0;
  border-radius: 8px;
  color: #166534;
}

The HTML:
Create a hidden container right next to or inside your form element.
<form id="contactForm">
  <!-- Your existing form fields here -->
  <button type="submit" id="submitBtn">Send Message</button>
</form>

<!-- This starts hidden, waiting for JavaScript to reveal it -->
<div id="successMessage" class="hidden">
  <h3>✨ Message Sent Successfully!</h3>
  <p>Thank you for reaching out. I will get back to you as soon as possible.</p>
</div>

The JavaScript Updates:
Modify your previous fetch success block to toggle the classes

// ... inside your fetch().then() block where response.status == 200:
if (response.status == 200) {
  // Hide the form entirely
  form.classList.add('hidden');
  
  // Show the success message container
  const successContainer = document.getElementById('successMessage');
  successContainer.classList.remove('hidden');
}
